## Logwatch 0.1.4 — Windows x64

Java·SQL·XML 로그를 실시간으로 보는 터미널 프로그램입니다. ZIP을 압축 해제하고 해당 폴더에서 PowerShell 또는 ezTerm을 열어 실행하세요.

~~~powershell
.\logwatch.exe
.\logwatch.exe 'C:\server\logs\application.log'
.\logwatch.exe --dump
~~~
