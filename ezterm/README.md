# ezTerm portable (Windows x64)

Download and extract ezTerm-portable-windows-x64.zip, then run ezterm.exe.
Microsoft Edge WebView2 Runtime must be available on the PC.
This EXE-only build does not include the optional VcXsrv distribution.
