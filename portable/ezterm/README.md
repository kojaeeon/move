# ezTerm portable (Windows x64)

Extract ezTerm-portable-windows-x64.zip, then run ezterm.exe with the helix folder beside it.
Press Ctrl+Shift+E in an SSH, CMD or PowerShell tab to open the ezedit command prompt.
SSH: run from an idle shell prompt; pwd prefills the remote folder before you append a file name.
Microsoft Edge WebView2 Runtime must be available on the PC.
This EXE-only build does not include the optional VcXsrv distribution.
